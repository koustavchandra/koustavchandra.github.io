# koustavchandra.github.io

Personal site, built by GitHub Pages (Jekyll) from the HTML5 UP "Editorial" theme, dark palette.

- Page content: `index.md`, `_includes/banner.html`, `_includes/sidebar.html`.
- Research-card figures: `python3 figures/make_figures.py` regenerates `assets/images/research/` from `figures/src/`.
- CV: edit `CV/*.tex`; GitHub Actions compiles it to `assets/pdf/CV.pdf` on push.
